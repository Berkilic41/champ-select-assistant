Privacy Policy

Effective date: 2026-05-31 · Champ Select Assistant ("the App")

This document explains what data the App accesses, how it uses that data, and what it deliberately does not do.

Summary

  • No telemetry. The App sends no data to any analytics or tracking service.
  • Data stays local. All data is stored only on your own computer.
  • No accounts. There is no registration, login, or cloud sync.

Data we access

The App only accesses the following data, belonging to the local player currently logged into League of Legends:

DataSourcePurpose
Recent match historyLeague Client (LCU)Comfort / recommendation scoring
Champion masteryLeague Client (LCU)Recommendation ranking
Champion-select session stateLeague Client (LCU)Live recommendations
Server/language preference, weight settingsValues you enterApp configuration

This data is stored only in a local SQLite database and never leaves your device.

How we use it

  • Data is processed on your device only, to produce champion-select recommendations.
  • No data is shared with third parties, sold, or uploaded to any server.

Aggregated meta data (server-side)

To compute the meta (champion win/pick/ban rates, lane matchups, common builds), a scheduled server-side job samples high-elo public games. Only aggregated statistics are stored server-side — no individual user's personal data. The Riot API key used for this is stored only on the server-side proxy and is never embedded in the distributed App.

External connections (public static content only)

The App connects to the following services for public static content that contains no personal data:

  • ddragon.leagueoflegends.com and cdn.communitydragon.org — champion/item images and static game data (Data Dragon / Community Dragon).
  • Aggregated meta (win/pick/ban) statistics for the current patch.

These requests carry no personal identifier (PUUID, name, or match ID).

Riot Developer API key

  • The App does not require a Riot developer API key for normal use.
  • An optional key may be kept only in a local .env file; it is never embedded in the binary and never logged.

Retention and deletion

  • All data lives in a SQLite file in your local application-data folder.
  • Uninstalling the App or deleting that file permanently removes all of your data.

Children's privacy

The App is subject to League of Legends' age requirements and does not intend to collect data specifically from children.

Changes

If this policy is updated, the effective date will change and it will be noted in the changelog.
